# MyPetakom
The Faculty of Computing, Universiti Malaysia Pahang Al Sultan Abdullah (UMPSA) has established a 
student association named Persatuan Teknologi Komputer (Petakom). The association coordinates and 
manages various events and activities for the faculty students, which are eligible for co-curricular merits. 
However, many processes related to the association, such as membership registration, are still performed 
manually. Your software development team is responsible to design a web-based solution to manage the 
administrative tasks of Petakom, named MyPetakom.
